# S24 条件期望漂移 / κ / 候选 H2 对照

已完成。**没有找到达到开发门槛的 W/U；正式 L3 仍为 ABSTAIN / NOT_ESTABLISHED。**
没有启动 κ=2048/4096 的最终验证，也没有替换或修改旧 L2/L3 结果。

## 本轮固定与改变

- 固定规范 GF S24：连续24个采样状态 decoded hazard margin >= 0 的窗口反复出现。
- 固定 SafeDreamer checkpoint、CCEPlanner、完整 RSSM + planner carry、192步路径、B=1、ell=0.8。
- 复用12条训练路径和8条开发路径，共111/74个共同物理锚点；W未接受锚点分别35/28个。
- 原训练每锚点32个后继，新增96个，构成128个。前32个完全相同，形成嵌套配对对照。
- GPU 从同一个完整状态复位补采333个查询块，共10,656个后继，约147.7秒。
- 训练19个候选：W wide、U sublevel 网络保持不变；400次更新，种子W=73/U=41。
  小网络的 PyTorch CPU 训练与评估共46.9秒；采样加训练评估约3.2分钟。
- W训练 margin 为0.01/0.05/0.10；U为0.001/0.03。
- 比较保留逐转移辅助项（权重0.5）的κ=32控制组，与删去该辅助项、只用条件均值漂移的κ=32/128组。
  原有 shaping 项仍保留；“只用条件均值”是指漂移损失，不是删除所有辅助监督。
- U另比较 H1 与 **候选** H2（I=F）。H2只在候选core外训练漂移；没有修改监测器为吸收态。
- 所有评估判据始终为 W漂移 <= -0.01、U漂移 <= 0，没有放宽门槛。

## H2 core 的退出检查

I暂定义为F，即产品状态中的“当前已连续24个状态安全”。它不是一个已经证明安全不变的物理区域。

| 数据 | core锚点 | 后继数 | 退出core的后继 |
| --- | --- | --- | --- |
| 原训练κ32 | 76 | 2,432 | 0 |
| 扩充训练κ128 | 76 | 9,728 | 0 |
| 复用开发κ256 | 46 | 11,776 | 0 |

训练κ128包含原κ32，不能把两行当作独立数据相加。
结论仅为 **SAMPLED_NO_EXIT**。论文H2要求所有允许后继都留在I，以及全局F⊆I⊆C等条件。
本轮没有证明这些条件；接受后仍可能因新hazard将计数器重置，不能把F直接当成合法免检区。

## 这轮最重要的诊断

1. expected-only W在35个训练锚点全部通过，但开发最多12/28：训练拟合并不是当前唯一问题，泛化仍差。
2. 原训练路径共有2,304条转移，其中282条从未接受状态出发。去掉逐转移项后，W漂移监督只剩35个不同锚点；κ变大并未增加锚点覆盖。
   这提示删除辅助项同时损失了覆盖/顺序监督，但小样本单种子结果不能确定唯一原因，也不能判定条件期望方法本身无效。
3. 逐转移硬下降比论文要求强。此次对照不能反过来证明它应当作为证明条件；更合理的下一项开发实验是增加不同训练锚点及其条件后继，或加入不要求每步强下降的软返回进度监督。
4. 不建议现在把同一批锚点的κ直接升到4096。即使忽略采样修正，raw仍未达到开发目标。
5. B=1下大margin不是免费参数：在保留区域内到接受集前持续满足期望负漂移，会约束期望返回时间；不能预设任意大的统一margin都可行。

## 统计与正式结论

开发集的256个后继已经在前几轮用于选模型，本轮是适应性复用。记录的固定slack≈0.13695计数只用于敏感性诊断，**不是新的95%置信结果**。
CSV导出了每个候选的min/q10/median/q90/max；anchor_drifts.csv保留逐锚点均值和值。

```text
Development numeric gate: NOT_MET (W: none; U: none)
H2 invariance: NOT_ESTABLISHED
Global L3: ABSTAIN
Infinite recurrence probability lower bound: unavailable
Final validation: NOT_RUN
```

即使日后raw达到90%，也不自动成为全局L3证书：仍需独立验证、cell/Lipschitz推广、区域覆盖/包含、有效保留条件、起点期望及collar风险界。
本轮既没有证明规范为假，也没有证明有效W/U不存在。
