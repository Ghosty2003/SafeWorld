# 连续 48 状态安全区间的 recurrence 候选筛选

规范：GF G[0,47](decoded hazard margin >= 0)。
使用已有 100 条、每条 100 transitions / 101 states（t=0..100）的
SafeDreamer CCEPlanner imagination 路径。初始条件为 decoded goal distance >= 1.0。
源文件哈希与原 provenance 一致，hazard AP 与 decoder 重算值一致。
没有新采样、训练证书、统计校准或发证；原 L2 文件保持不变。

| 有限路径指标 | 结果 |
| --- | ---: |
| 至少出现一次连续 48 状态安全区间 | 100/100 |
| 至少出现两个不重叠的 48 状态安全区间 | 97/100 |
| 第 51–100 步中包含完整的 48 状态安全区间 | 100/100 |
| t=0..100 全部无 hazard | 87/100 |
| 各路径最长安全段长度的最小值 | 93 个状态 |
| 各路径最长安全段长度的中位数 | 101 个状态 |

100 条都有重叠的多个安全窗口；总计 5352 个窗口，这些窗口高度相关，
不可以把它们作为 5352 个独立统计样本。两个不重叠窗口需要至少 96 个
安全状态；这解释了为何至少一个窗口为 100/100 而两个为 97/100。
没有路径出现两段被 hazard 分隔的、各自至少 48 状态的安全段；这并非
失败，因为该规范不要求中间故意经历危险，一直安全同样符合无限延伸语义。

监控器：连续安全计数达到 48 时接受；保持安全时继续接受，遇 hazard
立即清零，不使用 L2 的永久吸收式成功标志。该接受状态无限多次出现
与目标无限规范对应，但本次只观察有限前缀，未检验证书。

同批数据前 64 步也全部出现一个安全窗口；65 个状态不可能放下两个
不重叠的 48 状态窗口，不能把这个零当成 recurrence 失败。

结论：比此前双 goal 区域候选有更强的有限行为证据，值得继续做更长
imagination 开发路径和 L3 证书研究。当前输出为 NOT_EVALUATED，
不是 WARRANT，也不是无限 recurrence 成功率 100%。
这批旧数据已用于多次规范筛选，不能作为冻结后新的独立校准/测试集。

测试：11 项相关单元测试通过（边界、重叠、非吸收重置、因果性等）。
